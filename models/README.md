# 学習済み重み (.kmm、int8)

| ファイル | 構成 | 大きさ | 想定チャンク | dev 300 カナ CER (チャンク逐次) | 全文脈 | 想定端末 (実測 RTF) |
|---|---|---|---|---|---|---|
| `ja_v10_i8_c32.kmm` | 16 層 / d=176 / ff 704 / 4 ヘッド (約 13M) | 13.4 MB | 32 (1,280 ms) | 23.25% (chunk 32) / 24.50% (chunk 16) | 21.0% | ESP32-P4 360 MHz ×2 コア: RTF 0.85 (chunk 32)。PC、ブラウザ (WebAssembly) |
| `ja_v10s_i8_c16.kmm` | 8 層 / d=176 (約 6.5M) | 7.1 MB | 16 (640 ms) | 27.42% (chunk 32) / 28.82% (chunk 16) | 24.8% | ESP32-S3 240 MHz ×2 コア: RTF 0.93 (chunk 16) |
| `ja_v11a_i8_c32.kmm` (`_c16` は既定チャンクが違うだけ) | 16 層 / d=256 / ff 1024 / 4 ヘッド (約 30M) | 28.1 MB | 32 (1,280 ms) | **19.82%** (chunk 32) / 20.97% (chunk 16) | 17.6% | PC (AVX2 で RTF 0.04)、ブラウザ。端末には大きい (P4 で RTF 1.7 前後の見込み) |

- 出力はカタカナ (長音「ー」・促音「ッ」を含む)。語彙は SentencePiece 1,024 で、token 表はファイルの中にある。
- 動的チャンクで学習しているので、同じ重みを `--chunk 0` (全文脈) / 16 / 32 のどれでも使える。ヘッダの chunk/left は既定値 (CLI も端末も省略時はこれを使う)。
- 学習データは ReazonSpeech 約 3,800 時間、教師 (読みの正解) は sbintuitions/kana-whisper。dev も同じ教師の読みを正解にした発話なので、
  上の CER は「教師との一致率」であって人手の正解に対する値ではない。
- 実機では発話の前に音 (無音・雑音) が続いているぶん、dev の数字より 1 ポイントほど悪くなる (`docs/design.md` の位相の節)。
- 由来と権利: 学習音声は ReazonSpeech (CDLA-Sharing-1.0、著作権法 30 条の 4 の情報解析目的で利用。音声・字幕そのものは再配布しない)、
  読みの教師は sbintuitions/kana-whisper (MIT)。学習して得た重みは CDLA の「結果 (Results)」で、CDLA 側の制約は受けない。
- **重みのライセンス**: v11a は**ゼロから学習** (NeMo の重みを使っていない) なので **Apache-2.0**。v10 / v10s は **CC-BY-4.0**。v10 / v10s は NVIDIA NeMo `stt_en_conformer_ctc_small` の公開重み (CC-BY-4.0) を初期値に微調整した系統 (v1 → v3 → v5 → v9 → v10、v5 → v6 → v7 → v8 → v9s → v10s) なので、
  NVIDIA への帰属表示つきで CC-BY-4.0 に従う (NOTICE 参照)。100M 級 (v12、7,000 時間、準備中) もゼロから学習で Apache-2.0 の予定。コードは Apache-2.0。
